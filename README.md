# スキマフレーズ帳

スキマ時間に、日常でよく使う英語フレーズを場面ごとに覚えるための Web アプリです。
単語ではなく「その場面ですぐ使える一文」を、赤シートのカードで声に出して練習します。

## 主な機能

- **今日のカード**：開くとすぐ練習が始まります。1回 3・5・10 枚から選べます（約1〜4分）
- **赤シートめくり**：場面と日本語を見て英語を声に出し、タップでめくって答え合わせ。答えを見る前に、最初の単語だけ出すヒントもあります
- **復習の自動スケジュール**
  - 「言えた！」：1日後 → 3日後 → 7日後 … と間隔をあけて再登場。3回続けて言えたら「覚えた」
  - 「もう一回」：同じ回の最後と、次の回にもう一度出てきます
- **80フレーズ（10場面×8）**：あいさつ・相づち・聞き返し・お願い・カフェ・買い物・道と交通・空港とホテル・困ったとき・仕事。それぞれに使う場面、相手とのやりとり例、ニュアンスのポイント付き
- **場面別の一覧と検索**：一覧では「英語をかくす」で赤シートモードにできます
- **読み上げ**：ブラウザの音声合成（Web Speech API）で英語を再生。速さは「ふつう／ゆっくり」
- **記録**：覚えた数・連続日数・今日の枚数をブラウザに保存
- ライト／ダークモード対応、スマホ表示向け

パソコンではキーボードでも操作できます（Space：めくる、1：もう一回、2：言えた）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | デザイン |
| `phrases.js` | 場面とフレーズのデータ |
| `app.js` | 練習・復習・検索・読み上げの処理 |
| `favicon.svg` | アイコン |

HTML / CSS / JavaScript だけで、ビルドやインストールは不要です。

## 手元で動かす

`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで確認したい場合は、このフォルダで次を実行して http://localhost:8000 を開きます。

```sh
python3 -m http.server 8000
```

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリのルートに置いて push します
2. リポジトリの **Settings → Pages** を開きます
3. **Build and deployment** の Source を「Deploy from a branch」、Branch を `main`、フォルダを `/ (root)` にして Save します
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

スマホで開いて「ホーム画面に追加」しておくと、アプリのようにすぐ起動できます。

## フレーズを追加・編集する

`phrases.js` の各場面のリストに、次の形で追加します。

```js
{en:"Can I get a medium latte, please?",                          // 覚える英語
 ja:"ラテのMサイズをください。",                                    // 日本語の意味
 when:"カフェで注文するとき",                                       // 使う場面
 tip:"I want ~ より Can I get ~? が自然でていねい。",               // ポイント
 pre:["店員","Hi, what can I get for you?","いらっしゃいませ。ご注文は？"],          // 相手のひと言（なくてもOK）
 post:["店員","Sure. For here or to go?","かしこまりました。店内でお召し上がりですか？"]} // 相手の返事（なくてもOK）
```

- 記録はフレーズの順番（例：`eat-3` ＝ カフェ・レストランの3番目）で保存しています。新しいフレーズは各リストの**末尾**に追加してください。途中に入れると、それ以降のフレーズの記録がずれます。
- 場面を増やすときは、`SITUATIONS` に `{id, ja, en}` を追加し、`PHRASES` に同じ `id` のリストを作ります。フレーズ数や場面数の表示は自動で変わります。

## 記録について

記録はブラウザの localStorage に保存されます。端末やブラウザごとに別々で、ほかの端末とは共有されません。ブラウザのサイトデータを消すと記録も消えます。

## メモ

- 文字は Google Fonts（Shantell Sans、Zen Kaku Gothic New）を読み込んでいます。オフラインのときは端末のフォントで表示されます。
- 読み上げの声は端末やブラウザによって変わります。音が出ないときは、音量や消音モードを確認してください。
